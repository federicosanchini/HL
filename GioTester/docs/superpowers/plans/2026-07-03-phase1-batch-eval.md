## Global constraints
- **Determinism absolute.** `numpy.random.Generator(PCG64(seed))` only. **Builtin `hash()` is FORBIDDEN anywhere in `src/evolution/`** (per-process salted) — use `hashlib.sha256`. No wall-clock in any output.
- Canonical JSON: `json.dumps(obj, sort_keys=True, separators=(",",":"), allow_nan=False)`. `allow_nan=False` makes an accidental `inf`/`nan` raise loudly instead of emitting non-RFC `Infinity`. Disabled bracket legs serialize as `null`, never `inf` (see P1).
- Fingerprint = `{engine_semantics_version, data_window_hash, scorer_version:"s1", gene_library_version:"t1"}`. **`data_window_hash` is computed per evaluated window** from `(timeline[0].isoformat(), timeline[-1].isoformat(), n_bars, sorted(perps))` — so in-sample and holdout folds get DISTINCT hashes → distinct fingerprints → no cross-fold collision.
- Digest store key = `(genome_hash, fingerprint_hash, record_type)` where `record_type ∈ {insample, holdout, baseline}`. Append-only JSONL.
- Holdout: metrics NEVER in an `insample` record; a separate `holdout` record type, joined only by Skeptic/report tooling.
- `src/__init__.py` untouched except P1's additive export if needed. Commit per task; staged files only; never `git add -A`.

### Task P2 — Scorer [M] — `src/evolution/scoring.py` (statistical lens gating)
Pure functions over `SimResult`:
- `gross_notional_series(result)` = per-bar Σ|per_perp_position| (signed entry-notional). `peak_gross = max(series)`; `normalized_pnl = (final_equity - initial) / max(peak_gross, initial)` (zero-trade → denom=initial → 0, not NaN).
- `bootstrap_pnl_ci(total_equity, sd_window_hash, block_bars=336, n_boot=500)`: circular block bootstrap on per-bar equity **diffs**; **seed derived from data_window_hash only** (common random numbers → apples-to-apples CI overlap across genomes, per §2 "fixed RNG seed"); each resample **truncated to exactly N diffs** before summing; return 5th/95th pct of resampled total PnL normalized by the same `max(peak_gross, initial)`. Block 336 (2 weeks) is the compromise vs holding periods up to 720 — **document: lower-CI tie-breaking is trustworthy only within comparable holding regimes; cross-regime leans on Sortino/max-DD fallback** (§2).
- `margin_headroom(result)`: min over bars of `(equity - maintenance) / equity` using the EXACT per-bar `per_perp_maintenance` (P1). Guard: skip/clamp bars where `equity <= eps`; all-non-finite → documented sentinel `-inf`-free value (e.g. `0.0` stamped). No entry-notional approximation anymore.
- `score_v1(components) -> float`: base = lower-CI normalized PnL; **liquidation penalty ADDITIVE and sign-independent**: `if n_liquidated>0: base -= LIQ_PENALTY` (`LIQ_PENALTY=1.0`, one full unit of return-on-capital, stamped s1) — ANY liquidating genome sinks below ANY comparable clean one regardless of sign; complexity penalty `-0.001*total_free_params`; headroom penalty linear to `-0.05` when headroom<0.1. Constants = scorer_version "s1"; changes bump it.
Tests (hand-built SimResult fixtures): CI determinism (same window-seed → identical interval); **negative-score liquidated genome ranks strictly BELOW negative-score clean genome** (the sign-bug regression test — MUST include negative scores); zero-trade → 0 not NaN; headroom exact vs a known short position (short losing → maintenance grows → headroom shrinks, no optimism); resample length == N.

### Task P3 — Digest-maker + store [M] — `src/evolution/digest.py`
`make_digest(result, genome, fingerprint, record_type) -> dict` and `make_baseline_digest(result, baseline_id, fingerprint) -> dict` (null genome/kind-tuple fields, keyed on synthetic id e.g. `"baseline:EWP"`, `"placebo:seed=0"`). Fields: normalized PnL + CI, Sortino/max-DD (from `metrics_total`), margin headroom, n_liq, trade count (n_opened+n_closed), PnL concentration (top-5 share of |realized| over execution_events incl. liquidation-close events), long/short attribution (long_pnl/short_pnl/liq_*), per-month PnL signs (from timeline+total_equity), when-earned equity quartile timestamps, benchmark fields null (joined later), genome spec+hash+kind-tuple (or baseline id), fingerprint, `record_type`, `status:"ok"`, `scorer_version`.
`DigestStore(path)`:
- `append(digest)`: **repair-before-append** — on open, seek EOF; if last byte != `\n`, truncate to last newline (drop crash artifact) BEFORE writing. Then skip if an `ok` record for `(genome_hash|baseline_id, fingerprint_hash, record_type)` exists; else append canonical JSON line.
- `load()`: parse lines tolerating a trailing partial line; resolve duplicate keys **ok-supersedes-error** (an `ok` record overrides a prior `error`).
- **Single-writer**: main process only (if P5 adds workers, results funnel to one appender).
Tests: roundtrip; **status-aware skip** (error record does NOT block re-eval; ok does); ok-supersedes-error on load; crash-artifact tail tolerated + repaired on next append; merge-corruption case (partial line without newline + next append → repair prevents corruption).

### Task P4 — Windows, placebo, EWP [M] — `src/evolution/windows.py`
- `split_windows(sd) -> (insample_sd, holdout_sd)`: holdout = last 25% bars; embargo = 720 bars before it; in-sample = bars before embargo. **Assert `insample_bars > 0`** (wires §9 short-window check — raise loudly with computed bounds if the data window is too short). **Holdout warm-up lead-in**: `holdout_sd` INCLUDES the 720 embargo bars as an unscored prefix (drives observe()/latching so stateful signals enter warm); scoring starts accounting at the true holdout start — thread a `score_from_bar` offset into the digest/scoring path for holdout records. `ranks_by_release` (day-keyed dict) is carried UNCHANGED into both windows (runner looks up by day); only the four bar-indexed arrays + timeline are sliced. Per-window `data_window_hash` differs (P1).
- Placebo: `signal`/`placebo_random(seed=0)` gene in `src/genome/library.py` — score = `int.from_bytes(sha256(f"{asset}|{bar_index}|{seed}".encode()).digest()[:8],"big") / 2**64` ∈ [0,1); stateless, deterministic, works on release_bar timing; documented baseline-only (excluded from evolution ops).
- EWP baseline mechanics: `load_trader("Traders/EWP.py", **shared_kwargs)` → `run_backtest_prepared` → `make_baseline_digest(..., "baseline:EWP", ...)`. Specify shared_kwargs (leverage=1, min_notional_usd=10, n, etc. as tester.py injects).
Tests: split boundaries exact + embargo length + no overlap; insample>0 assertion raises on a too-short synthetic window; ranks resolve inside each window; warm-up prefix present in holdout_sd with score_from_bar set; placebo determinism across process restarts (subprocess); placebo scores in [0,1).
