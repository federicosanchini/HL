This project aims to build a fully automated quantitative trading framework inspired by the work of Timothy DeLise (@jefferythewind). 

The objective is to create a complete, self-contained system capable of collecting market data, processing signals, executing trades, and evaluating performance without manual intervention.

The framework focuses on the HyperLiquid perpetual futures ecosystem and integrates an external oracle, provided in our implementation by CrowdCent, to supply reliable, real-time signals and model outputs. These serve as the foundation for strategy evaluation, risk management, and portfolio decisions.

The long-term goal is to develop a robust research and execution environment that is transparent, reproducible, and extensible, allowing systematic strategies to be prototyped and deployed with different Oracles.
